# Python Development - Level 1

This repository contains Level 1 Python internship projects completed as part of the Codveda Python Development Internship.

## Projects

### 1. Simple Calculator
A basic calculator that performs:
- Addition
- Subtraction
- Multiplication
- Division

#### Features
- User-friendly menu
- Function-based implementation
- Division by zero error handling

#### Technologies Used
- Python

---

### 2. Number Guessing Game
A Python game where the user guesses a randomly generated number between 1 and 100.

#### Features
- Random number generation
- Multiple attempts
- Feedback messages:
  - Too High
  - Too Low
- Success message when guessed correctly

#### Technologies Used
- Python
- Random Module
